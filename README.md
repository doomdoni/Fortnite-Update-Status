# 포트나이트 실시간 서버 상태 & 패치노트 트래커 (단일 파일 버전)

포트나이트(Fortnite)의 실시간 서버 가동 상태, 점검 시작 및 **서버 다운 해제(오픈) 예정 시간 카운트다운**, 최신 클라이언트 패치 버전과 인게임 패치 뉴스를 실시간으로 제공하는 올인원 웹 대시보드입니다.

---

## 깃허브(GitHub Pages) 배포 방법

1. [GitHub](https://github.com)에서 새 레포지토리를 만듭니다.
2. 이 폴더의 **`index.html` 파일 단 1개만** 깃허브에 드래그 앤 드롭으로 업로드(Commit)합니다.
3. 레포지토리 **Settings** -> **Pages** -> Branch를 **main**으로 설정 후 **Save**를 누르면 끝!
4. 폴더 경로 깨짐 없이 모든 버튼(새로고침, 탭 전환, 모달 팝업, 맵 확대, 알림)과 실시간 연동이 100% 완벽 작동합니다.
