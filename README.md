# 포트나이트 실시간 서버 상태 & 패치노트 트래커 (Fortnite Status Live)

포트나이트(Fortnite)의 실시간 서버 가동 상태, 점검 시작 및 **서버 다운 해제(오픈) 예정 시간 카운트다운**, 최신 클라이언트 패치 버전과 인게임 패치 뉴스를 실시간으로 제공하는 웹 대시보드입니다.

---

## 주요 기능

1. **실시간 서버 상태 모니터링**
   - Epic Games Statuspage 공식 인프라와 연동하여 배틀로얄 매치메이킹, 계정 로그인, 게임 서비스 등의 정상 여부를 실시간 추적합니다.
   - 30초 주기 자동 백그라운드 폴링 및 수동 새로고침 지원.

2. **서버 다운 해제(점검 종료) 실시간 카운트다운**
   - 정기 점검 또는 패치 배포 중일 때, 서버 점검 해제(종료) 예상 일시까지 남은 시간을 시:분:초 단위로 실시간 카운트다운합니다.
   - 점검 일정이 없을 때에는 다음 예정 점검 안내 또는 정상 가동 지표를 표시합니다.

3. **최신 클라이언트 빌드 & 패치노트**
   - 현재 배포된 메인 패치 버전(예: `v32.00` 등)과 AES 빌드 스트링 제공.
   - 한국어(KO) 공식 인게임 패치 뉴스 피드 (배틀로얄, 세이브 더 월드, 포크리 탭 분리 지원).
   - 카드 클릭 시 상세 패치 설명 모달 팝업.

4. **서버 오픈 데스크톱 웹 알림**
   - 브라우저 Web Notification API를 연동하여 서버 점검이 끝나고 서버가 오픈되거나 새 패치가 배포되면 데스크톱 알림을 발송합니다.

5. **정제된 게이밍 대시보드 UI**
   - AI 느낌의 과도한 이모티콘을 모두 배제하고, Lucide 벡터 SVG 아이콘과 다크 테마 게이밍 레이아웃 적용.
   - 모바일, 태블릿, 데스크톱 완벽 반응형.

---

## 실행 방법

- `index.html` 파일을 더블 클릭하여 크롬, 엣지, 웨일 등 모던 웹 브라우저에서 바로 열 수 있습니다.
- 또는 정적 웹 호스팅(GitHub Pages, Vercel, Netlify 등)에 업로드하여 즉시 웹사이트로 서비스할 수 있습니다.

---

## 기술 스택
- **HTML5 & Vanilla JavaScript (ES6 Modules)**
- **Tailwind CSS (CDN)**
- **Lucide Icons**
- **Data APIs**: Epic Games Statuspage API & Fortnite-API.com
